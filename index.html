Install

Run it on your Mac in minutes.

  1. Install Ollama from ollama.com
  2. Pull a local model such as llama3.1
  3. Clone or download the TerminAI project and run it
Terminal 
ollama pull llama3.1
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 terminai.py
