DOWNLOAD & SETUP

Try TerminAI
on your Mac.

The current release is a Python terminal project—not a signed, standalone Mac application. Download the source from GitHub and run it with local Ollama.

ⓘ

No .app download yet. The “Download” link below takes you to the public source repository. A standalone macOS app is not currently available.

Quick setup

  1. 1

    Install Ollama

    Download and open Ollama for Mac. Keep it running.

    Get Ollama ↗
  2. 2

    Download a model

    In Terminal, pull a model supported by your hardware.

    ollama pull llama3.1
  3. 3

    Get TerminAI

    On GitHub choose Code → Download ZIP, then unzip and open Terminal in the project folder.

    Download source from GitHub ↗
  4. 4

    Install and run

    Use the project folder in Terminal, then run:

    python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 terminai.py

    Type /exit to quit the chat.

WHAT YOU NEED

Before you begin

  • A Mac with Python 3 installed
  • Ollama installed and running
  • A downloaded local model
  • Internet for initial downloads
Privacy note

Once installed, local chats use Ollama on your machine. Model and software downloads need internet access.
